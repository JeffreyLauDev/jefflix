# Security

Please don't report security problems in public issues. Email **jeffylau007@gmail.com** with the details, or message the developer privately on [Discord](https://discord.gg/KSp8ZRMvQP). You'll get a reply within a few days.

Jefflix stores only your Jellyfin server address and sign-in token, on your own device, and talks to no server other than yours.
